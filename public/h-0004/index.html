Pythonで SyntaxError: invalid non-printable character U+3000 が出たときの原因と直し方（全角スペース）【実行して確認】

※本記事はアフィリエイト広告（PR）を含みます。

公開日 2026-11-07　更新日 2026-11-11　手順・エラー解決 / Python

この記事の手順は 2026年11月7日 に下記の環境で実際に実行して確認しました。

結論：コードの中に全角スペースが入っています。半角スペースに置き換えると直ります

SyntaxError: invalid non-printable character U+3000 の U+3000 は「全角スペース」の文字番号です。日本語入力のままスペースキーを押すと入りやすく、見た目では半角スペースと区別がつきません。この環境では、エラーの出た行の全角スペースを半角スペースに置き換えると、プログラムが最後まで動きました。

sed -i '3s/　/ /g' calc.py
実行ログ
$ python3 calc.py
税込み：1320円

検証環境

項目バージョン
OSUbuntu 24.04.5 LTS
PythonPython 3.13.18

お使いの環境（OS・バージョン）が違うと、出力やエラー文が少し変わることがあります。

エラーの再現：計算式の途中に全角スペースが入っている

税込み価格を計算する短いプログラムを用意しました。3行目の * のあとに、全角スペースが1つ入っています。画面で見ると、普通のスペースとほとんど同じに見えます。

実行ログ
$ cat calc.py
# 商品の税込み価格を計算する　（消費税10%）
price = 1200
total = price *　110 // 100
print(f"税込み：{total}円")

実行すると、次のエラーになりました。

実行ログ
$ python3 calc.py
  File "/tmp/run-h-0004/calc.py", line 3
    total = price *　110 // 100
                   ^
SyntaxError: invalid non-printable character U+3000

エラー文の読み方は次のとおりです。

  • line 3 は、問題のある行の番号です。
  • ^ の印は、問題の文字がある位置を指しています。ここでは * のすぐ後ろです。
  • invalid non-printable character は「（コードとしては）使えない、目に見えない文字」という意味で、U+3000 がその文字の番号（全角スペース）です。

原因：Pythonは全角スペースを区切りとして扱わない

Pythonの公式ドキュメント（字句解析）では、コードの部品と部品のあいだの空白として使えるのは、半角スペース・タブ・改ページ文字だと決められています。全角スペースはこの中に入っていないため、コードの中に出てくると「使えない文字」としてエラーになります。

全角スペースがどこにあるかは、grep で探せます。検索する文字として全角スペースを1文字入れて実行しました。

実行ログ
$ grep -n '　' calc.py
1:# 商品の税込み価格を計算する　（消費税10%）
3:total = price *　110 // 100

1行目と3行目の2か所が見つかりました。ただし、エラーになったのは3行目だけです。1行目は # から始まるコメントなので、中に全角スペースがあっても問題になりません。文字列（" で囲んだ部分）の中も同じです。

直し方：エラーの行の全角スペースを半角スペースに置き換える

エディタで3行目の全角スペースを消して、半角スペースを打ち直すのが一番確実です。ここでは、同じことをコマンドで行いました。sed -i '3s/　/ /g' は「3行目の全角スペースをすべて半角スペースに置き換える」という意味です。

実行ログ
$ sed -i '3s/　/ /g' calc.py

$ cat calc.py
# 商品の税込み価格を計算する　（消費税10%）
price = 1200
total = price * 110 // 100
print(f"税込み：{total}円")

$ python3 calc.py
税込み：1320円

エラーが消えて、計算結果が表示されました。置き換えたあとにもう一度探すと、コメントの全角スペースだけが残っています。コメントの中なので、このままで動きます。

実行ログ
$ grep -n '　' calc.py
1:# 商品の税込み価格を計算する　（消費税10%）

行番号を付けずにファイル全体を置き換えると、文字列の中の全角スペース（表示したい文章の一部）まで変わってしまいます。置き換えはエラーの出た行に絞るのがおすすめです。

うまくいかないとき

  • 字下げ（インデント）に全角スペースを使っている場合も、同じエラーになりました。この場合、^ の印は行の先頭を指します。
実行ログ
$ cat greet.py
def greet(name):
　　return f"こんにちは、{name}さん"

print(greet("山田　太郎"))

$ python3 greet.py
  File "/tmp/run-h-0004/greet.py", line 2
    　　return f"こんにちは、{name}さん"
    ^
SyntaxError: invalid non-printable character U+3000

全角スペース1つを半角スペース2つに置き換え、半角スペース4つの字下げにすると動きました。4行目の文字列の中の全角スペース（「山田　太郎」）は、置き換えずにそのまま表示されています。

実行ログ
$ sed -i '2s/　/  /g' greet.py

$ cat greet.py
def greet(name):
    return f"こんにちは、{name}さん"

print(greet("山田　太郎"))

$ python3 greet.py
こんにちは、山田　太郎さん
  • 全角スペースを直しても、同じ行で別の文字のエラーが出ることがあります。全角のかっこ・コロン・イコールなど、ほかの全角記号もコードの中では使えません。この記事では全角スペース以外は実行して確かめていません。使える文字の決まりは、Python公式ドキュメントの「字句解析」をご確認ください。
  • エディタの設定で全角スペースを目に見える記号で表示できるものがあります。設定の方法はお使いのエディタの公式ドキュメントをご確認ください。

独学で行き詰まったときに、講座で体系的に学び直したい場合は、オンラインのプログラミングスクールもあります。

まとめ

SyntaxError: invalid non-printable character U+3000 は、コードの中に全角スペースが入っているときのエラーです。エラー文の行番号と ^ の位置で場所を確かめ、その行の全角スペースを半角スペースに置き換えると、この環境ではプログラムが動きました。コメントと文字列の中の全角スペースはそのままで問題ありません。
