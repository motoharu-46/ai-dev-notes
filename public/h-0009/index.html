Pythonで FileNotFoundError: [Errno 2] No such file or directory が出たときの原因と直し方（相対パスと実行場所）【実行して確認】

※本記事はアフィリエイト広告（PR）を含みます。

公開日 2026-11-12　更新日 2026-11-12　手順・エラー解決 / Python

この記事の手順は 2026年11月12日 に下記の環境で実際に実行して確認しました。

結論：相対パスは「スクリプトの場所」ではなく「実行した場所」から探されます。スクリプトの場所を基準にしたパスに変えると直ります

open("data.csv") のような相対パスは、Pythonを実行したときの作業ディレクトリ（カレントディレクトリ）から探されます。スクリプトと同じフォルダにファイルがあっても、別のフォルダから python3 sales/total.py のように実行すると見つからず、FileNotFoundError になります。この環境では、Path(__file__).resolve().parent でスクリプトの場所を取り、そこからファイルのパスを作ることで、どこから実行しても読み込めるようになりました。

BASE_DIR = Path(__file__).resolve().parent
csv_path = BASE_DIR / "data.csv"

検証環境

項目バージョン
OSUbuntu 24.04.5 LTS
PythonPython 3.13.18

お使いの環境（OS・バージョン）が違うと、出力やエラー文が少し変わることがあります。

エラーの再現：ファイルはあるのに別のフォルダから実行すると見つからない

sales というフォルダに、商品と値段を書いた data.csv と、その合計を出す total.py を置きました。total.py は data.csv を相対パスで開いています。作業ディレクトリは、sales の1つ上の /tmp/run-h-0009 です。

実行ログ
$ pwd
/tmp/run-h-0009

$ ls sales
data.csv
total.py

$ cat sales/total.py
import csv

with open("data.csv", encoding="utf-8") as f:
    rows = list(csv.DictReader(f))

total = sum(int(row["price"]) for row in rows)
print("合計:", total, "円")

この場所から total.py を実行すると、次のエラーになりました。

実行ログ
$ python3 sales/total.py
Traceback (most recent call last):
  File "/tmp/run-h-0009/sales/total.py", line 3, in <module>
    with open("data.csv", encoding="utf-8") as f:
         ~~~~^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
FileNotFoundError: [Errno 2] No such file or directory: 'data.csv'

エラー文の読み方は次のとおりです。

  • line 3 は、エラーが起きた行の番号です。3行目の open("data.csv", ...) で失敗しています。
  • [Errno 2] No such file or directory は「そのファイルもフォルダも見つからない」という意味です。
  • 最後の 'data.csv' は、Pythonが実際に開こうとしたパスです。ここがフォルダ名のない data.csv だけになっているのがポイントです。

ls sales の結果のとおり、data.csv は total.py と同じフォルダにちゃんとあります。それでも見つからないのは、Pythonが別の場所を探しているからです。

原因：相対パスは作業ディレクトリから探される

Pythonが相対パスをどこから探しているのかを確かめるために、作業ディレクトリ（os.getcwd()）、data.csv を絶対パスに直した結果、スクリプトそのものの場所を表示するプログラムを用意しました。

実行ログ
$ cat sales/debug.py
import os
from pathlib import Path

print("作業ディレクトリ:", os.getcwd())
print("data.csv の探し先:", Path("data.csv").resolve())
print("スクリプトの場所:", Path(__file__).resolve().parent)

$ python3 sales/debug.py
作業ディレクトリ: /tmp/run-h-0009
data.csv の探し先: /tmp/run-h-0009/data.csv
スクリプトの場所: /tmp/run-h-0009/sales

スクリプトは /tmp/run-h-0009/sales にありますが、data.csv は作業ディレクトリの /tmp/run-h-0009 の直下で探されていました。そこには data.csv がないため、エラーになります。

試しに sales フォルダに移動してから同じように実行すると、作業ディレクトリとスクリプトの場所が一致し、元の total.py もそのまま動きました。

実行ログ
$ cd sales

$ python3 debug.py
作業ディレクトリ: /tmp/run-h-0009/sales
data.csv の探し先: /tmp/run-h-0009/sales/data.csv
スクリプトの場所: /tmp/run-h-0009/sales

$ python3 total.py
合計: 500 円

「自分のパソコンでは動くのに、別の場所から実行したり、エディタの実行ボタンで動かしたりすると失敗する」という場合は、多くがこの作業ディレクトリの違いです。エディタによっては、開いているプロジェクトのフォルダを作業ディレクトリにして実行するため、スクリプトのあるフォルダと食い違うことがあります。

直し方：スクリプトの場所を基準にパスを作る

毎回 cd してから実行する方法でも動きますが、実行する場所を気にしなくて済むように、スクリプトの中でパスを作ります。__file__ には実行中のスクリプトのパスが入っているので、Path(__file__).resolve().parent でスクリプトのあるフォルダが分かります。そこに / "data.csv" をつなげると、スクリプトと同じフォルダの data.csv を指すパスになります。

実行ログ
$ cat sales/total.py
import csv
from pathlib import Path

BASE_DIR = Path(__file__).resolve().parent
csv_path = BASE_DIR / "data.csv"

with open(csv_path, encoding="utf-8") as f:
    rows = list(csv.DictReader(f))

total = sum(int(row["price"]) for row in rows)
print("合計:", total, "円")

$ python3 sales/total.py
合計: 500 円

sales の1つ上の /tmp/run-h-0009 から実行して、エラーが消えて合計が表示されました。さらに別の場所（/tmp）に移動してから実行しても、同じ結果になりました。

実行ログ
$ cd /tmp

$ python3 run-h-0009/sales/total.py
合計: 500 円

resolve() は、パスを絶対パスに直すためのものです。付けておくと、python3 sales/total.py のように相対パスでスクリプトを指定して実行した場合でも、正しくスクリプトのフォルダが取れます。

うまくいかないとき

  • ファイル名やフォルダ名の打ち間違いでも、同じエラーになります。次の例では、data.csv を date.csv と書き間違えています。エラー文の最後に表示されるパスと、ls で表示される実際のファイル名を見比べると、違いが分かりました。
実行ログ
$ python3 -c 'open("sales/date.csv")' 2>&1 | tail -n 1
FileNotFoundError: [Errno 2] No such file or directory: 'sales/date.csv'

$ ls sales/*.csv
sales/data.csv
  • 作業ディレクトリの考え方や os.getcwd()・os.chdir() については、公式ドキュメントの os モジュールの「ファイルとディレクトリ」の項目をご確認ください。パスの組み立て方（/ でつなぐ書き方や resolve()）は pathlib のページに説明があります。
  • Jupyter Notebook のように __file__ が使えない実行方法では、この直し方はそのままでは使えません。その場合は os.getcwd() で作業ディレクトリを確かめてから、そこからの相対パスを書いてください。

独学で行き詰まったときに、講座で体系的に学び直したい場合は、オンラインのプログラミングスクールもあります。

まとめ

FileNotFoundError: [Errno 2] No such file or directory は、ファイルがあるのに出る場合、相対パスがスクリプトの場所ではなく作業ディレクトリから探されていることが原因でした。この環境では、Path(__file__).resolve().parent を基準にしたパスに書き換えると、どのフォルダから実行してもファイルを読み込めました。
