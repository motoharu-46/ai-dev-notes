Pythonで TypeError: 'NoneType' object is not subscriptable が出たときの原因と直し方【実行して確認】

公開日 2026-11-09　更新日 2026-11-09　手順・エラー解決 / Python

この記事の手順は 2026年11月9日 に下記の環境で実際に実行して確認しました。

結論：[ ] を付けた変数の中身が None になっています。None が入る理由をつぶすか、None のときの処理を分けると直ります

TypeError: 'NoneType' object is not subscriptable は、「None に対して ["name"] や [0] のような添字（[ ]）を使おうとした」という意味のエラーです。よくある原因は、関数が値を返さずに終わって None を返していることと、list.sort() のように None を返すメソッドの戻り値を変数に入れていることの2つです。この環境では、None のときの処理を if user is None: で分けるか、sort() を sorted() に置き換えると、エラーが消えて最後まで動きました。

    if user is None:
        print("ユーザーが見つかりません:", user_id)
    else:
        print(user["name"])

検証環境

項目バージョン
OSUbuntu 24.04.5 LTS
PythonPython 3.13.18

お使いの環境（OS・バージョン）が違うと、出力やエラー文が少し変わることがあります。

エラーの再現：見つからなかったときに関数が何も返していない

ユーザーの一覧からIDで1人を探して、名前を表示する短いプログラムを用意しました。一覧にいない suzuki を探しています。

実行ログ
$ cat user.py
users = [
    {"id": "tanaka", "name": "田中"},
    {"id": "sato", "name": "佐藤"},
]

def find_user(user_id):
    for user in users:
        if user["id"] == user_id:
            return user

user = find_user("suzuki")
print(user["name"])

実行すると、次のエラーになりました。

実行ログ
$ python3 user.py
Traceback (most recent call last):
  File "/tmp/run-h-0006/user.py", line 12, in <module>
    print(user["name"])
          ~~~~^^^^^^^^
TypeError: 'NoneType' object is not subscriptable

エラー文の読み方は次のとおりです。

  • line 12 は、エラーが起きた行の番号です。その下に、問題の行そのものが表示されています。
  • ~~~~^^^^^^^^ の印は、Python 3.11 以降で表示される目印です。~ の部分（user）に ^ の部分（["name"]）を付けたところで失敗した、という意味です。
  • 'NoneType' object は「None という値」のことです。not subscriptable は「添字（[ ]）を付けて中身を取り出せない」という意味です。

つまり、12行目の時点で変数 user の中身が None だった、ということが分かります。エラーが出た行そのものではなく、「その変数に None が入った場所」を探すのが直し方の近道です。

原因：関数が return せずに最後まで進むと None が返る

Pythonの公式チュートリアル（関数を定義する）には、return 文がないまま関数の最後まで進んだ場合、関数は None を返すと書かれています。今回の find_user は、一致するユーザーが見つかったときだけ return user を実行します。一致しないまま for 文が終わると、何も返さずに関数を抜けるため、戻り値は None になります。

本当に None が返っているかを確かめるために、見つかる場合と見つからない場合の戻り値を repr() で表示しました。

実行ログ
$ cat debug.py
users = [
    {"id": "tanaka", "name": "田中"},
    {"id": "sato", "name": "佐藤"},
]

def find_user(user_id):
    for user in users:
        if user["id"] == user_id:
            return user

print(repr(find_user("tanaka")))
print(repr(find_user("suzuki")))

$ python3 debug.py
{'id': 'tanaka', 'name': '田中'}
None

tanaka では辞書が返り、suzuki では None が返っていました。エラーの原因は、見つからなかった場合の None に ["name"] を付けたことです。

直し方：None のときの処理を分ける

「見つからないこともある」のは正しい動きなので、None が返ったときの処理を呼び出し側で分けます。判定には if user is None: を使います。関数の最後には、見つからないときは None を返すことが読んで分かるように return None を書きました（書かなくても動きは同じです）。見つかる場合と見つからない場合の両方を試すために、tanaka と suzuki を順に探しています。

実行ログ
$ cat user.py
users = [
    {"id": "tanaka", "name": "田中"},
    {"id": "sato", "name": "佐藤"},
]

def find_user(user_id):
    for user in users:
        if user["id"] == user_id:
            return user
    return None

for user_id in ["tanaka", "suzuki"]:
    user = find_user(user_id)
    if user is None:
        print("ユーザーが見つかりません:", user_id)
    else:
        print(user["name"])

$ python3 user.py
田中
ユーザーが見つかりません: suzuki

エラーが消えて、見つかった tanaka は名前を、見つからなかった suzuki はメッセージを表示しました。None との比較には == ではなく is を使うよう、Pythonの公式スタイルガイド（PEP 8）が勧めています。

うまくいかないとき

  • list.sort() の戻り値を変数に入れている場合も、同じエラーになりました。次の例では、点数を大きい順に並べて1位を表示しようとしています。
実行ログ
$ cat sort.py
scores = [72, 95, 64]
ranking = scores.sort(reverse=True)
print("1位:", ranking[0])

$ python3 sort.py
Traceback (most recent call last):
  File "/tmp/run-h-0006/sort.py", line 3, in <module>
    print("1位:", ranking[0])
                  ~~~~~~~^^^
TypeError: 'NoneType' object is not subscriptable

sort() はリストそのものを並べ替えるメソッドで、戻り値は None です。実際に表示して確かめました。

実行ログ
$ python3 -c 'print([72, 95, 64].sort())'
None

並べ替えた新しいリストがほしいときは、組み込み関数の sorted() を使います。置き換えると動きました。

実行ログ
$ cat sort.py
scores = [72, 95, 64]
ranking = sorted(scores, reverse=True)
print("1位:", ranking[0])

$ python3 sort.py
1位: 95

scores.sort(reverse=True) を単独の行で実行してから scores[0] を使う書き方でも同じ結果になります。append()・extend()・reverse() など、リストを直接書き換えるメソッドも戻り値は None なので、戻り値を変数に入れないように気をつけてください。

  • 正規表現の re.match() や辞書の get() など、「見つからないと None を返す」関数はほかにもあります。どの関数が None を返すことがあるかは、公式ドキュメントのその関数の説明（戻り値の項目）をご確認ください。

まとめ

TypeError: 'NoneType' object is not subscriptable は、None が入った変数に [ ] を付けたときのエラーです。エラーの行の変数に None が入った場所を探すと、この環境では「return しないまま関数が終わっていた」「sort() の戻り値を使っていた」の2つが原因でした。None のときの処理を if ... is None: で分けるか、sorted() に置き換えると、プログラムは最後まで動きました。
