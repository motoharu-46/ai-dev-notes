Pythonで UnicodeDecodeError: 'utf-8' codec can't decode byte が出たときの原因と直し方（日本語CSV）【実行して確認】

公開日 2026-11-07　更新日 2026-11-07　手順・エラー解決 / Python

※本記事はアフィリエイト広告（PR）を含みます。

この記事の手順は 2026年11月6日 に下記の環境で実際に実行して確認しました。

結論：ファイルがShift_JIS（cp932）なのに、UTF-8として読んでいるのが原因です

日本語のCSVをPythonで読んだときに UnicodeDecodeError: 'utf-8' codec can't decode byte が出たら、ファイルの文字コードと、読むときに指定した文字コードが合っていません。Windows版のExcelで「CSV」として保存したファイルは、多くの場合Shift_JIS系の cp932 です。読み込むときに encoding="cp932" を指定すると、この環境ではエラーが消えて正しく読めました。

with open("sales.csv", encoding="cp932") as f:
    print(f.read())

検証環境

項目バージョン
OSUbuntu 24.04.5 LTS
PythonPython 3.13.18
pandaspandas 3.0.5

お使いの環境（OS・バージョン）が違うと、出力やエラー文が少し変わることがあります。

エラーの再現：Shift_JISのCSVをUTF-8で読む

まず、Excelで保存した日本語CSVと同じ状態を作るため、cp932 で書き込んだCSVファイルを用意しました。

# Excelで保存した日本語CSVと同じ、Shift_JIS（cp932）のファイルを作る
rows = "商品名,価格\nりんご,120\nみかん,80\n"
with open("sales.csv", "w", encoding="cp932", newline="") as f:
    f.write(rows)

このファイルを、文字コードにUTF-8を指定して読むコードです。

with open("sales.csv", encoding="utf-8") as f:
    print(f.read())

実行すると、次のエラーになりました。

実行ログ
$ python3 read_ng.py
Traceback (most recent call last):
  File "/home/dev/work/csv-sjis/read_ng.py", line 2, in <module>
    print(f.read())
          ~~~~~~^^
  File "<frozen codecs>", line 325, in decode
UnicodeDecodeError: 'utf-8' codec can't decode byte 0x8f in position 0: invalid start byte

最後の行が要点です。「ファイルの0バイト目にある 0x8f というバイトを、UTF-8として読めなかった」という意味です。0x8f は「商」をcp932で表したときの1バイト目です。エラー文に出るバイトの値（0x82、0x83、0x8f など）はファイルの中身によって変わりますが、原因は同じです。

原因：ファイルの文字コードと、読むときの指定が合っていない

open() の encoding は、ファイルの中身をどの文字コードとして解釈するかの指定です。Pythonの公式ドキュメントでは、cp932 は日本語のShift_JIS系の文字コードとして標準エンコーディングの一覧に載っています。今回のファイルは cp932 で保存されているため、UTF-8として読もうとすると、UTF-8では使われないバイトの並びにぶつかってエラーになります。

ファイルの種類を調べる file コマンドでは、次のように表示されました。日本語の文字コード名までは出ないため、「UTF-8ではない」ことの目安として使います。

実行ログ
$ file sales.csv
sales.csv: CSV Non-ISO extended-ASCII text

直し方：encoding="cp932" を指定して読む

encoding を cp932 に変えたコードです。

with open("sales.csv", encoding="cp932") as f:
    print(f.read())
実行ログ
$ python3 read_ok.py
商品名,価格
りんご,120
みかん,80

エラーが消え、日本語も正しく表示されました。

pandasの read_csv でも同じ直し方

pandasの read_csv() も、何も指定しないとUTF-8として読みます。同じファイルを読むと、同じエラーになりました（長いトレースバックの最後の3行です）。

実行ログ
$ python3 read_pandas_ng.py 2>&1 | tail -3
  File "pandas/_libs/parsers.pyx", line 2076, in pandas._libs.parsers.raise_parser_error
  File "<frozen codecs>", line 325, in decode
UnicodeDecodeError: 'utf-8' codec can't decode byte 0x8f in position 0: invalid start byte

read_csv() にも encoding 引数があります。cp932 を指定したコードです。

import pandas as pd

df = pd.read_csv("sales.csv", encoding="cp932")
print(df)
実行ログ
$ python3 read_pandas_ok.py
   商品名   価格
0  りんご  120
1  みかん   80

うまくいかないとき

  • encoding="cp932" でもエラーになる場合は、ファイルがShift_JIS系ではない可能性があります。Excelの「CSV UTF-8」形式で保存したファイルは、先頭にBOMという目印が付いたUTF-8です。この形式については、この記事では実行して確認していないため、Pythonの公式ドキュメントの codecs（標準エンコーディングの一覧）で utf-8-sig の説明をご確認ください。
  • errors="ignore" を付けるとエラーは出なくなりますが、読めなかった文字が黙って消えます。データが欠けるため、文字コードを正しく指定するほうが安全です。

まとめ

日本語CSVで UnicodeDecodeError: 'utf-8' codec can't decode byte が出るのは、Shift_JIS系（cp932）のファイルをUTF-8として読んでいるためです。open() でも pandas.read_csv() でも、encoding="cp932" を指定すると、この環境では正しく読めました。
