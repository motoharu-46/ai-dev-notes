## 結論：列名の前に見えない空白が付いています。空白を取り除いて読み込むと直ります

`print(df)` では「金額」という列が表示されているのに、`df["金額"]` で `KeyError: '金額'` になることがあります。この環境で調べたところ、CSVの見出し行がカンマのあとに空白を入れて書かれていたため、列名が `' 金額'`（先頭に半角スペース付き）として読み込まれていました。`pd.read_csv()` に `skipinitialspace=True` を付けるか、読み込んだあとに `df.columns = df.columns.str.strip()` で空白を取ると、エラーが消えて合計が計算できました。

```python
df = pd.read_csv("sales.csv", skipinitialspace=True)
```

## エラーの再現：表示では列があるのに KeyError になる

売上のCSVを読み込んで、「金額」の列を合計する短いプログラムを用意しました。CSVは、カンマのあとに半角スペースを入れて見やすくした形です。手で書いたCSVや、ほかのツールから書き出したCSVでよく見かける書き方です。

```text 実行ログ
$ cat sales.csv
日付, 商品, 金額
2026-11-01, りんご, 120
2026-11-02, バナナ, 80
2026-11-03, りんご, 150

$ cat sum.py
import pandas as pd

df = pd.read_csv("sales.csv")
print(df)
print(df["金額"].sum())
```

実行すると、`print(df)` の表示では「金額」の列がちゃんと見えています。

```text 実行ログ
$ python sum.py 2>&1 | head -n 4
           日付    商品   金額
0  2026-11-01   りんご  120
1  2026-11-02   バナナ   80
2  2026-11-03   りんご  150
```

ところが、その次の行で次のエラーになりました。トレースバックは長いので、最後の3行だけを表示しています。

```text 実行ログ
$ python sum.py 2>&1 | tail -n 3
  File "/tmp/run-h-0007/.venv/lib/python3.13/site-packages/pandas/core/indexes/base.py", line 3823, in get_loc
    raise KeyError(key) from err
KeyError: '金額'
```

`KeyError: '金額'` は、「`'金額'` という名前の列が見つからない」という意味です。トレースバックの途中はpandasの内部のファイルなので、読むのは最後の1行と、自分のファイル（今回は `sum.py`）の行だけで足ります。

## 原因：列名に空白が含まれている

`print(df)` の表は、列名の前後の空白が目で見ても分かりません。そこで、列名を `df.columns.tolist()` でリストとして表示しました。リストで表示すると、文字列が `' '` で囲まれるので、空白の有無が分かります。

```text 実行ログ
$ cat check_columns.py
import pandas as pd

df = pd.read_csv("sales.csv")
print(df.columns.tolist())

$ python check_columns.py
['日付', ' 商品', ' 金額']
```

2列目と3列目の列名が、`' 商品'` と `' 金額'` のように先頭に半角スペースが付いた名前になっていました。`pd.read_csv()` は、カンマで区切った中身を（初期設定では）そのまま列名や値として扱います。そのため、カンマのあとの空白まで列名の一部になり、`'金額'` とは別の名前として扱われていました。

列が存在するのに KeyError が出るときは、まず `df.columns.tolist()` で本当の列名を確かめるのが近道です。

## 直し方：空白を取り除く

直し方は2つ試しました。

### 方法1：読み込んだあとに列名の空白を取る

`df.columns.str.strip()` は、すべての列名から前後の空白を取り除きます。結果を `df.columns` に入れ直します。

```text 実行ログ
$ cat fix_strip.py
import pandas as pd

df = pd.read_csv("sales.csv")
df.columns = df.columns.str.strip()
print(df.columns.tolist())
print(df["商品"].tolist())
print(df["金額"].sum())

$ python fix_strip.py
['日付', '商品', '金額']
[' りんご', ' バナナ', ' りんご']
350
```

列名の空白が取れて、`df["金額"].sum()` で合計の 350 が表示されました。ただし、「商品」の値を表示すると `' りんご'` のように、値の側にも空白が残っていました。この方法は列名だけを直すので、文字列の値で絞り込みや集計をするときは、値の空白にも注意が必要です。

### 方法2：読み込むときに空白を読み飛ばす（おすすめ）

`pd.read_csv()` の `skipinitialspace=True` は、区切り文字（カンマ）のあとの空白を読み飛ばす指定です。

```text 実行ログ
$ cat fix_skip.py
import pandas as pd

df = pd.read_csv("sales.csv", skipinitialspace=True)
print(df.columns.tolist())
print(df["商品"].tolist())
print(df["金額"].sum())

$ python fix_skip.py
['日付', '商品', '金額']
['りんご', 'バナナ', 'りんご']
350
```

列名と値の両方から空白が消えて、合計も計算できました。CSVのカンマのあとに空白が入っている場合は、この方法のほうが後の処理で困りにくいです。なお、`skipinitialspace=True` が読み飛ばすのはカンマの**あと**の空白です。列名の後ろ（カンマの前）に空白がある場合は、方法1の `str.strip()` も合わせて使ってください。この記事では、後ろに空白がある場合は実行して確かめていません。

## うまくいかないとき

- **`set_index()` で列をインデックスにしていた場合**も、同じ KeyError になりました。次の例では、「日付」をインデックスにしたあとで `df["日付"]` を使っています。

```text 実行ログ
$ cat index.py
import pandas as pd

df = pd.read_csv("sales.csv", skipinitialspace=True)
df = df.set_index("日付")
print(df.columns.tolist())
print(df["日付"])

$ python index.py 2>&1 | head -n 1
['商品', '金額']

$ python index.py 2>&1 | tail -n 3
  File "/tmp/run-h-0007/.venv/lib/python3.13/site-packages/pandas/core/indexes/base.py", line 3823, in get_loc
    raise KeyError(key) from err
KeyError: '日付'
```

列名の一覧から「日付」が消えています。`set_index()` は、指定した列を列からインデックス（行の名前）に移すためです。インデックスの値は `df.index` で取り出せます。列に戻したいときは `reset_index()` を使います。

```text 実行ログ
$ cat index_fix.py
import pandas as pd

df = pd.read_csv("sales.csv", skipinitialspace=True)
df = df.set_index("日付")
print(df.index.tolist())
df = df.reset_index()
print(df.columns.tolist())

$ python index_fix.py
['2026-11-01', '2026-11-02', '2026-11-03']
['日付', '商品', '金額']
```

- 列名の大文字・小文字の違い（`Price` と `price`）や、全角と半角の違いでも、列名は別のものとして扱われます。この場合も `df.columns.tolist()` で表示した名前と、コードに書いた名前を1文字ずつ見比べてください。
- 日本語のCSVを読み込んだときに `UnicodeDecodeError` が出る場合は、文字コードの問題です。[Pythonで UnicodeDecodeError が出たときの原因と直し方（日本語CSV）](/h-0901/) をご覧ください。

## まとめ

pandasで列が存在するように見えるのに `KeyError` が出るときは、列名に見えない空白が付いていることがあります。この環境では、カンマのあとに空白があるCSVで列名が `' 金額'` になっていました。`df.columns.tolist()` で本当の列名を確かめ、`skipinitialspace=True` で読み込むか `df.columns.str.strip()` で空白を取ると、エラーが消えて集計できました。
